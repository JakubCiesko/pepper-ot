    This thesis presents a scene-aware dialogue system for the Pepper robot. The goal is to enable Pepper to answer questions about its surroundings using visual perception, persistent scene memory, and language generation.

    The proposed architecture uses Pepper as a lightweight robot client responsible for interaction and image capture. Computationally demanding processing is moved to an external server. The server performs object detection, appearance-based object association, scene memory updates, Pepper people-perception metadata fusion, Set-of-Mark rendering, scene graph generation, question generation, and memory-grounded dialogue with large language models.

    The evaluation focuses on the quality of generated scene graphs, the effect of Set-of-Mark prompting, predicate and attribute vocabularies, vocabulary-size reduction, prompt formatting, and robot-side interaction latency. The results show that visual grounding for dialogue is feasible in this setting, but also sensitive to prompt design, vocabulary construction, detector quality, and latency.

\chapter*{Appendices}

The electronic appendix submitted in the IS MU Archive consists of the following archives:

\begin{itemize}
    \item \texttt{code.zip}: source code, configuration files, project documentation, scripts, and instructions for installing required third-party dependencies and models.
    \item \texttt{experiments\_and\_results.zip}: experiment configurations, evaluation outputs, measurement results, result tables, plots, logs, and other generated artifacts used in the thesis evaluation.
    \item \texttt{data.zip}: a sample of the data used for experiments. Instructions for obtaining or preparing additional data are provided in the \texttt{README.md} file in \texttt{code.zip}.
\end{itemize}

The submitted archives do not contain third-party software packages, virtual environments, downloaded model weights, or external datasets. These are referenced through installation and download instructions included in the project documentation.
