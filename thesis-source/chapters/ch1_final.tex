\chapter{Introduction}\label{chap:intro}

\section{Motivation}

Unlike screen-based assistants, social robots occupy the same physical space as their users. This embodiment changes what users expect from them. A person addressing a robot in a room may reasonably expect it to know what is nearby, who is present, and which objects are being discussed.

Pepper is a humanoid social robot built around spoken interaction, expressive motion, camera input, tablet output, and robot-native perception modules provided through the NAOqi platform. These capabilities make it a suitable platform for situated dialogue, but they also expose a central limitation: a robot that can speak about the world should be able to connect its speech to the world it perceives. In this thesis, Pepper is treated as a situated communication partner that answers questions about its perceived environment.

Recent Pepper-based systems show that this direction is technically and practically relevant. Pepper has been used as a teaching assistant and as a service robot, for example in library assistance with visual perception and OCR~\cite{sievers_humanoid_2025,trinquet_future_2025}. Other systems connect Pepper or similar robots to external language, vision, or retrieval components to support grounded dialogue~\cite{brad_retrieval-augmented_2025,grassi_grounding_2024,latif_physicsassistant_2024}. These works demonstrate that modern AI components can broaden what social robots can discuss. The central problem of this thesis is therefore not simply to attach a language model to Pepper, but to ground its answers in an explicit, dynamically updated model of the perceived scene.

In situated robot dialogue, this grounding cannot remain purely linguistic. The robot must also connect utterances to the perceived world using the visible objects, people, their attributes or relations. A grounded, scene-aware answer is therefore not merely any plausible sentence, but an answer constrained by what the robot currently perceives and remembers. 

Large language models (LLMs) make this issue more attainable. They can make robotic dialogue more flexible and natural than hand-written response templates or rigid dialogue states defined by dialogue management systems~\cite{aturhurra_leveraging_2024}. However, an LLM does not automatically know what Pepper currently sees. If the robot is asked about a laptop or a chair that is posed in front of it, the answer can only be supported by perception and memory rather than by the model's general language knowledge.

It is clear that object detection alone is not enough for this purpose. A detector can localize objects, return labels and bounding boxes, but it does not by itself say which object is next to which, what is on the table, or whether a person is looking at the robot. What is needed is a structured scene representation between low-level perception and high-level dialogue. Scene graphs provide such a representation by encoding objects, their attributes and relations~\cite{johnson_image_2015}. This makes them suitable for conversational grounding.

Another requirement on a really context-aware dialogue is persistence. Real interaction is not limited to one image. Pepper may look at the room, answer a question, move its head, observe another part of the scene, and later be asked about an object from a previous observation. The system therefore needs scene memory; It must preserve object identities across observations, update attributes and relations, and expose the resulting state to the dialogue layer.

Pepper also imposes a technical constraint. Modern object detectors, visual embedding models, captioning models, vision-language models (VLMs), and LLMs are too demanding to run as a full pipeline on Pepper's onboard hardware. In this thesis, Pepper is therefore used merely as a client, while an external machine performs the computationally expensive perception, memory, and language processing. This follows the same practical direction as previous Pepper systems that require computationally more able solutions for modern perception or dialogue capabilities~\cite{reyes_near_2018,trinquet_future_2025,brad_retrieval-augmented_2025,grassi_grounding_2024}.


This thesis is motivated by the need to connect these components into a single scene-aware dialogue system. The target setting is an ordinary indoor environment, such as an office, classroom, or computer laboratory. In this setting, the robot should be able to observe its surroundings, build a structured memory of relevant objects and relations, and use this memory when answering the user.

\section{Problem Statement and Objectives}

The central problem addressed in this thesis is how to enable the Pepper robot to conduct dialogue about its surroundings in a way that is grounded in perception and persistent across observations. A scene-aware answer should not depend only on general language-model knowledge; it should also reflect what the robot has observed, what objects and people are present, and how these entities are related.

The thesis is system-oriented. It does not propose a new object detector, scene graph model, or language-model architecture. Instead, it investigates how existing perception, vision-language, and language components can be selected, combined, and adapted for a Pepper-based interaction pipeline.

The main objective is to design and implement a distributed architecture in which Pepper serves as the embodied interaction client, while an external server performs computationally demanding perception, memory, and language processing. Within this architecture, the system should detect relevant objects and people, preserve object identities across discontinuous observations, organize perceived entities into a structured scene memory, and use this memory as grounding context for dialogue.

\section{Main Contributions}

The main contribution of this thesis is the design, implementation, and evaluation of a complete dialogue system for the Pepper robot. The system combines robot-side interaction, server-side multimodal perception, persistent scene memory, and grounded language generation into a single pipeline.

At the representation level, it introduces a perception-to-memory pipeline that detects objects and people, supports identity persistence across discontinuous observations, and stores the perceived scene in a structured form suitable for dialogue. 


At the interaction level, it implements a dialogue layer that uses this stored scene state as grounding context when answering questions about the environment. 


Finally, the thesis evaluates the system with respect to scene graph quality, Set-of-Mark prompting, vocabulary design, prompt formatting, and robot-side interaction latency.
